How to Run and Use the program:

1.Compile the program using a C++ compiler: g++ MatrixOperation.cpp -o MatrixOperation

2.Run the program using: ./MatrixOperation

3.Enter the number of rows and columns for the first matrix when prompted

4.Enter all values of the first matrix; only valid numeric input is accepted

5.Enter the number of rows and columns for the second matrix

6.Enter all values of the second matrix

7.Matrix addition is performed if both matrices have the same dimensions

8.Matrix multiplication is performed if the number of columns of the first matrix equals the number of rows of the second matrix

9.The result of the valid matrix operation(s) is displayed on the screen

10.Enter 1 to perform another operation or 0 to exit the program
