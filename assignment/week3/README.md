How to Run and Use the program:

1.Compile the program using a C++ compiler: g++ -Iinclude src/MatrixCalculatorApp.cpp src/MatrixCalculatorApp

2.Run the program using: ./src/MatrixCalculatorApp

3. Enter operation you want to choose

4.Enter the number of rows and columns for the first matrix when prompted

5.Enter the number of rows and columns for the second matrix

4.Enter all values of the first matrix; only valid numeric input is accepted

6.Enter all values of the second matrix

7.Matrix addition or multiplication is performed according to choice

9.The result of the valid matrix operation(s) is displayed on the screen

10.Enter 1 to perform another operation or 0 to exit the program
